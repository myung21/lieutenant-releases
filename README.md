# Lieutenant — Releases

Download the latest version of **Lieutenant**, the Y Innovations command center.

This repository contains **release binaries only** — no source code.
Source lives in the private `Lieutenant` repository.

## Download

Go to the [**latest release**](https://github.com/myung21/lieutenant-releases/releases/latest) and pick your platform:

| Platform | File |
|---|---|
| **Mac** (Apple Silicon) | `Lieutenant-<version>-arm64.dmg` |
| **Windows** (64-bit) | `Lieutenant-Setup-<version>.exe` |

## First install

The app is not code-signed, so each OS shows a one-time warning:

- **Mac** — open the `.dmg`, drag Lieutenant to Applications, then **right-click the app → Open** and confirm. Double-clicking the first time will be blocked; right-click → Open is required once.
- **Windows** — run the `.exe`. On the blue "Windows protected your PC" screen, click **More info → Run anyway**.

## Updates

After the first install, Lieutenant updates itself. It checks on launch and every
few hours; when a new version is ready you'll be prompted to restart. You should
never need to download from this page again.
